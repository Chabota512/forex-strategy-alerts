---
name: myFXtool UI direction
description: User's standing visual scope for the myFXtool interface.
---

Keep myFXtool's existing visual language. Improve sections that feel inconsistent, group related controls more clearly, and use nested expandable option lists where they improve organization. Avoid broad redesigns.

**Why:** The user likes the current interface and wants selected areas to feel more consistent with it.

**How to apply:** Refine existing components and their hierarchy in place; preserve the app's established look unless the user asks for a broader redesign.
